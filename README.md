How to use:
Open VSCode and import your cookies in the "domestika_session" variable.
You can also change the subtitle language directly underneath it, along with the resolution (both defaulting to English and 1920x1080 respectively).

Once prompted, enter your link (After clicking the 1st unit and getting the url from there) and sit back and mute the tab while you wait for your video and subtitles to download.
No need to input any path, since it gets the path from the file itself and creates paths accordingly. Anyway, it'll cycle through each unit, download the video and subtitles and then it'll close itself.
I am currently unaware of how to make this stealthy and headless--any pointers would be nice.

How to install dependencies:

Open up your VSCode terminal (Ctrl + `) and type the following command
```terminal
pip install -r .\requirements.txt
```
